# CasGPT

CasGPT là ứng dụng web một trang giúp các đại lý Castrol Garage tạo nhanh Facebook content với giao diện đơn giản, gọn gàng và chuyên nghiệp.

## Tính năng chính

- Bộ template theo mục tiêu thực tế của garage (khuyến mãi, nhắc lịch bảo dưỡng, ra mắt dịch vụ, tri ân khách hàng).
- Form nhập liệu tối giản, dễ dùng cho người không rành công nghệ.
- Xem trước thiết kế theo thời gian thực với định dạng 1080x1080.
- Tông màu chuyên nghiệp theo phong cách tối giản kiểu Apple Store.

## Chạy local

```bash
python3 -m http.server 8000
```

Sau đó mở: `http://localhost:8000`
